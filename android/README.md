# زاجِل لأندرويد

تطبيق Kotlin مع Jetpack Compose، فوق محرّك زاجِل نفسه (`zajil-core`) عبر `crates/zajil-android` وUniFFI. القرار وأسبابه في [ADR-0012](../docs/adr/0012-android.md)، والمراحل A1 إلى A5 في [ROADMAP](../docs/ROADMAP.md).

> **English summary.** A Gradle project (AGP 9.4.1, Gradle 9.8.2, Kotlin 2.4.21, JDK 17). `./gradlew assembleDebug` also builds the Rust engine for arm64-v8a with cargo-ndk and generates its Kotlin bindings (`build-engine.sh`). Every build checks the merged manifest against ADR-0012's permissions and exported components. Emulator tests use the local `zajil-testserver` through `adb reverse`, never the internet.

## ما فيه (A1)

| الملف | ما يفعله |
|---|---|
| `build-engine.sh` | يبني المحرّك (`libzajil_android.so`، release، `arm64-v8a`، API 26) ويولّد ملف Kotlin منه بـ `uniffi-bindgen`. يشغّله Gradle قبل كل بناء (المهمة `buildEngine`) |
| `app/build.gradle.kts` | البناء، و`CheckManifest`: يفشل البناء إن طلب الـ manifest المدموج صلاحية أو صدّر مكوّنًا غير ما في ADR-0012 (القسم 11) |
| `ZajilApp.kt` | يحمّل المحرّك، ويعطي `Context` لفاحص الشهادات (`Tls.init`) |
| `downloads/DownloadCenter.kt` | قائمة التحميلات (`files/downloads.json`، كتابة آمنة بـ `AtomicFile`)، والمحرّك، ونقل الملف المكتمل |
| `downloads/DownloadService.kt` | الخدمة الأمامية (`dataSync`) وإشعار التقدم بأزرار «إيقاف مؤقت» و«إلغاء التحميل». تعمل فقط ما دام تحميل يعمل |
| `downloads/BootReceiver.kt` | بعد إعادة تشغيل الهاتف: يكمل وحده قبل أندرويد 15، ومن 15 إشعار «اضغط للاستكمال» |
| `downloads/Publisher.kt` | ينقل الملف المكتمل إلى `Download/Zajil` (MediaStore، وبالمسار في أندرويد 8 و9) |
| `ui/` | تصميم D5 (ADR-0012، القسم 16): الشريط العائم في `Root.kt`، والرئيسية، و«كل التحميلات» و«تفاصيل التحميل» (`DownloadsScreens.kt`)، و«تحميل جديد»، وصفحة الفيديو، والمتصفح، والحماية، والطوابير، والإعدادات. الألوان في `Theme.kt`، والأيقونات الخطية في `Icons.kt`، والأجزاء المشتركة في `Parts.kt` |
| `make-icons.py` | يكتب أيقونات التطبيق والإشعار من `assets/icon/zajil-mark.svg` نفسه، بلا إعادة رسم |

النصوص في `res/values/strings.xml` (العربية، الافتراضية) و`res/values-en/strings.xml`. ولغة التطبيق تُختار أيضًا من إعدادات أندرويد (لغة لكل تطبيق).

## البناء

يحتاج: Android SDK (منصة 37، وNDK ‏29.0.14206865)، وJDK 17، وRust بهدف `aarch64-linux-android`، و`cargo-ndk`:

```bash
rustup target add aarch64-linux-android
```

```bash
cargo install cargo-ndk --version 4.1.2 --locked
```

ثم من مجلد `android/` (وفيه `local.properties` بسطر `sdk.dir=…`، ولا يُرفع إلى المستودع):

```bash
JAVA_HOME=/opt/homebrew/opt/openjdk@17/libexec/openjdk.jdk/Contents/Home ./gradlew assembleDebug
```

نسخة التطوير `io.github.motalim_ai.zajil.debug`، فتعيش بجانب النسخة المثبّتة. ونسخة release (`assembleRelease`) بلا توقيع: التوقيع في الـ CI فقط (A4).

## التجربة على المحاكي

الاختبارات لا تتصل بالإنترنت أبدًا: سيرفر الاختبار `zajil-testserver` يعمل على الجهاز المضيف، والتطبيق يصل إليه على `127.0.0.1` عبر `adb reverse`. (لا عبر `10.0.2.2`: من أندرويد 17 يحتاج التطبيق صلاحية «الشبكة المحلية» لعنوان خاص، وزاجِل لا يطلبها. ADR-0012، القسم 12.)

1. شغّل السيرفر من أعلى المستودع، ومعه ملف يُكتب فيه كل طلب كل ثانية:

   ```bash
   cargo run -p zajil-android --example emulator_server -- /tmp/zajil-requests.log
   ```

   يطبع بصمة SHA-256 للملف (50 ميجابايت عشوائية، وكل اتصال بسرعة 256 كيلوبايت/ث)، ورابطه، ورابط HTTPS بشهادة موقّعة ذاتيًا.
2. وصّل المنفذ:

   ```bash
   adb reverse tcp:8099 tcp:8099
   ```

3. ثبّت التطبيق والصق الرابط المطبوع واضغط «تحميل».

**ما جُرِّب في A1 (يدويًا، أندرويد 17، API 37، المحاكي `Adawat_Phone`):**

| الحالة | الخطوة | النتيجة |
|---|---|---|
| تحميل كامل | «تحميل» | البصمة تطابق، والملف في `Download/Zajil`، والإشعار يتغير مع التقدم |
| إيقاف مؤقت | «إيقاف مؤقت» عند 77%، ثم «استكمال» | توقفت الخدمة الأمامية، ثم طلب كل اتصال ما بعد آخر بايت محفوظ فقط، والبصمة تطابق |
| قتل العملية | `adb shell run-as <الحزمة> kill -9 <pid>` | أعاد أندرويد تشغيل الخدمة بعد ثانية، فكمل التحميل وحده، والبصمة تطابق |
| إيقاف إجباري | `adb shell am force-stop <الحزمة>`، ثم فتح التطبيق | بقي متوقفًا حتى الفتح (كما يريد المستخدم)، ثم كمل من آخر بايت محفوظ |
| إعادة تشغيل المحاكي | `adb reboot` أثناء التحميل | إشعار «تحميل متوقف، اضغط للاستكمال من حيث توقف»، و«استكمال» فيه كمل التحميل، والبصمة تطابق |
| شهادة موقّعة ذاتيًا | رابط HTTPS المطبوع (بعد `adb reverse` لمنفذه) | رُفض بـ `UnknownIssuer` من مخزن أندرويد: «شهادة الموقع غير صالحة، فلم يُحمَّل شيء» |
| نسخة release | `assembleRelease` موقّعة محليًا بمفتاح التطوير للتجربة فقط | R8 لم يكسر شيئًا: التحميل كمل، والحجم 6.2 ميجابايت |
| اللغتان | `adb shell cmd locale set-app-locales <الحزمة> --locales en` | الواجهة من اليسار إلى اليمين بالإنجليزية، ومن اليمين إلى اليسار بالعربية |

|---|---|---|

**تجربة التحديث (A4) على المحاكي، بلا مفتاح المشروع:**

1. نسخة أحدث: `./gradlew assembleDebug -Pzajil.testVersion=0.1.1`، وانسخ الـ APK إلى `serve/android-v0.1.1/zajil-android-0.1.1-arm64-v8a.apk`.
2. ملف التحديث لها في `serve/android-channel/latest-android.json` (بصيغة ADR-0012 القسم 15)، ووقّعه بمفتاح الاختبار: `cargo run -p zajil-android --example sign_for_test -- serve/android-channel/latest-android.json` (يطبع المفتاح العام).
3. `ZAJIL_SERVE_DIR=serve cargo run -p zajil-android --example emulator_server -- /tmp/log`، ويطبع `base`.
4. النسخة الأقدم: `./gradlew assembleDebug -Pzajil.updateBase=<base> -Pzajil.updateTestKey=<المفتاح>`، وثبّتها، و`adb reverse tcp:8099 tcp:8099`.

| الحالة | النتيجة |
|---|---|
| فتح زاجِل | بطاقة «زاجِل 0.1.1 متاحة (٣٤ م.ب)» بملاحظاتها |
| APK معدّل بايتًا واحدًا | «رُفض التحديث: لم يُتحقق من توقيعه أو بصمته، فلم يُثبَّت شيء.» والملف محذوف |
| الـ APK السليم | «نزلت زاجِل 0.1.1 وتُحقق منها.»، ثم «تثبيت» يفتح صفحة «تثبيت التطبيقات غير المعروفة»، ثم نافذة أندرويد «هل المطلوب تحديث هذا التطبيق؟»، وبعدها النسخة 0.1.1 |

**التصميم المعتمد على المحاكي (2026-11-01):** الشاشات الخمس بالعربية والإنجليزية، فاتحًا وداكنًا، ومظهر «داكن» من الإعدادات والنظام فاتح. وملفات من مجلد `ZAJIL_SERVE_DIR` (أسماء عربية، وتحت `slow/` بطيئة) لترى التحميل يعمل:

| الحالة | النتيجة |
|---|---|
| مشاركة رابط PDF | «تحميل جديد» بالاسم والحجم والنوع، و«يكمل لو انقطع» و«8 اتصالات» |
| حد السرعة 512 ك.ب/ث | التحميلات معًا حوله، والوقت الباقي يظهر |
| رابط غير موجود (404) | «فشل · رفض السيرفر الطلب» وزر «إعادة المحاولة» |

| فيديو يوتيوب قصير | صورته ومدته وقناته، والأحجام لكل جودة، ثم ملف MP4 في `Download/Zajil` |

**الالتقاط السريع (2026-11-01، المحاكي):**

| الحالة | الخطوة | النتيجة |
|---|---|---|
| رابط منسوخ | نسخه، ثم الخروج والعودة إلى زاجِل | «حمّل الرابط المنسوخ؟» مرة واحدة؛ وبعد «لاحقًا» أو الإغلاق لا يعود، حتى لو نُسخ الرابط نفسه مرة أخرى |
| المربع | `adb shell cmd statusbar add-tile <الحزمة>/io.github.motalim_ai.zajil.CopiedLinkTile`، ثم فتح الإعدادات السريعة و`cmd statusbar click-tile` بنفس الاسم | نافذة شفافة فوق الشاشة بصفحة «حمّل الرابط المنسوخ؟» واسم الملف وحجمه؛ «ابدأ التحميل» يغلقها والملف ينزل في الخلفية |

**متصفح زاجِل (A6، 2026-11-01، المحاكي):** صفحات HTML في مجلد `ZAJIL_SERVE_DIR`. السيرفر يعطي كل ملف نوعه (html وm3u8 وts وmp4)، ويكتب في السجل الكوكيز والـ Referer لكل طلب. وقائمة HLS تُصنع بـ `ffmpeg -f hls` من أي mp4.

| الحالة | الخطوة | النتيجة |
|---|---|---|
| صفحة فيها mp4 | فتحها في «تصفّح» (الصفحة تضع كوكي) | «تحميل 1» فوق الصفحة (لا شيء يُرسم على الفيديو)، ثم «تحميل جديد» بمصدر «من المتصفح». وفي سجل السيرفر طلب المحرّك بالكوكي والـ Referer |
| العنوان | ضغطة عليه، ثم «تحديد الكل» و«نسخ»، ثم «مسح» و«لصق»، وتغيير آخره، ثم «اذهب» | العنوان كله محدد عند الضغط، والنسخ واللصق يعملان، وتُفتح الصفحة الجديدة |
| زر «تحميل» | «صغّر الزر»، ثم إعادة تثبيت زاجِل وفتح الصفحة، ثم ضغطة على الدائرة | دائرة فيها العدد، وبقيت بعد إعادة الفتح، ثم رجع الزر كاملًا |
| ملء الشاشة | زر ملء الشاشة في `<video>` وفي مشغّل يوتيوب، ثم تدوير المحاكي، ثم «رجوع» أو زر الخروج في يوتيوب | الفيديو وحده بلا أشرطة النظام، أفقيًا بعد التدوير، والفيديو يستمر؛ وبعد الخروج الصفحة كما كانت |
| إطفاء الحركة | `animator_duration_scale` = 0، ثم تغيير التبويب | الإشارة الزرقاء تقفز إلى التبويب بلا حركة |
| صفحة HLS | صفحة يطلب سكربتها `hls/master.m3u8` بنفسه، كما يفعل hls.js | «فيديو HLS»، ثم صفحة الفيديو بعنوان الصفحة، ثم ملف MP4 سليم (`ffprobe`: H.264 مع AAC، 20 ثانية) |
| يوتيوب ومقطع فيسبوك | فتح صفحة الفيديو في «تصفّح» | عنصر الصفحة وحده، ثم صفحة الفيديو. وفيسبوك: «الملف كما في الصفحة»، ونزل الملف |
| الوضع الخاص | صفحة تضع كوكي، ثم صفحة تعرض `document.cookie` | كوكي الوضع الخاص وحده، لا كوكيز الوضع العادي، ولا شيء في «زرتها مؤخرًا» |
| نهاية الوضع الخاص | إطفاؤه ثم تشغيله، أو الخروج من زاجِل ثم فتحه | الصفحة نفسها: `(none)` |
| تبديل مجموعتي التبويبات | الانتقال بين «عادي» و«خاص» | تبقى المجموعتان مفتوحتين؛ اختُبر على محاكي Android 17 |
| إغلاق التبويبات الخاصة | طلب إغلاقها من المتصفح | منطق الإغلاق اختُبر على محاكي Android 17؛ لم يُعَد اختبار تعديل عرض الزر |
| «إدارة تسجيلات الدخول» | من الإعدادات، ثم حذف `127.0.0.1` | الصفحة في الوضع العادي: `(none)` |
