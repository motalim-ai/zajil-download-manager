# OCSP responders of the big certificate authorities (ADR-0012, section 17).
#
# rustls-platform-verifier checks revocation on Android with OCSP first,
# then the CA's revocation list (CRL), and its network security config lets
# the app use plain HTTP only to CRL hosts (the answers are signed). With
# OCSP blocked, Android downloaded the whole list for every new connection:
# DigiCert's is 11.4 MB, and parsing it filled the app's heap (Facebook's
# video servers, 2026-11-01). These hosts let OCSP answer first, in a few
# KB; the build adds them to the library's own file
# (app/build.gradle.kts, `networkConfig`). A CA missing here falls back to
# its list, as before.
#
