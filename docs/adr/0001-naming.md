# ADR-0001: تسمية المشروع والمعرّفات

| البند | القيمة |
|---|---|
| الحالة | **مقبول** |
| التاريخ | 2026-10-23 (حُدِّث المعرّف في نفس اليوم بقرار المالك) |
| صاحب القرار | Motalim (@motalim-ai) |

## السياق
نحتاج أسماء ثابتة من البداية. تغيير الاسم بعد النشر صعب، لأنه يغيّر معرّفات الإضافة وتسجيل Native Messaging والحزم ومسارات الإعدادات عند المستخدمين.

## القرار

| الاستخدام | الاسم |
|---|---|
| الاسم الرسمي الكامل (الإنجليزية) | **Zajil Download Manager** |
| الاسم الرسمي الكامل (العربية) | **زاجِل لإدارة التحميل** |
| الاسم القصير في الواجهة والقوائم | **Zajil** في الواجهة الإنجليزية، و**زاجِل** في الواجهة العربية |
| المستودع على GitHub | `motalim-ai/zajil-download-manager` |
| الأمر في سطر الأوامر، وأسماء الحزم والمكتبات | `zajil`، والمكتبات `zajil-*` (مثل `zajil-core`) |
| المعرّف العكسي للتطبيق (app id) | `io.github.motalim_ai.zajil` |
| اسم مضيف Native Messaging | `io.github.motalim_ai.zajil.host` |
| امتداد الملف الجزئي وملف الحالة | `.zajil-part` و`.zajil-state` |
| مجلد الإعدادات والبيانات | `zajil`، أو المعرّف العكسي حيث يتطلبه النظام |

**الكتابة العربية**: «زاجِل» بكسرة تحت الجيم في العناوين والمواضع البارزة، و«زاجل» بلا تشكيل مقبولة داخل النصوص الطويلة.

**أصل الاسم**: الحمام الزاجل الذي يوصل الرسائل.

## السبب
- **`zajil` قصير** ويُكتب بحروف لاتينية صغيرة فقط، وهذا مناسب لأسماء الأوامر والحزم في الأنظمة الثلاثة.
- **`io.github.motalim_ai.zajil`** مبني على حساب GitHub الذي نملكه فعلًا، فلا يحتاج حجز نطاق، ولا يتعارض مع مالك نطاق آخر. وهو الشكل المعتاد لمعرّفات مشاريع GitHub في Flatpak. الشرطة `-` في اسم الحساب `motalim-ai` تُكتب `_`، لأن بعض الأنظمة لا تقبل الشرطة.
- **اسم مضيف Native Messaging** يجب أن يحتوي حروفًا صغيرة وأرقامًا و`_` و`.` فقط، و`io.github.motalim_ai.zajil.host` يحقق ذلك.

## العواقب
- لا نستخدم أي اسم أو شعار أو أيقونة تشبه IDM أو تُوهم بعلاقة به.
- **مسألة مفتوحة: معرّف الحزمة في ماك (bundle identifier).** حسب وثائق Apple، يقبل هذا المعرّف الحروف والأرقام والشرطة `-` والنقطة فقط، **ولا يقبل الشرطة السفلية `_`**. وحسب ما نعرف، حقل `identifier` في Tauri يطبق نفس القيد. يحتاج تحققًا في M4.
  - **البديل المقترح لماك وTauri فقط**: `io.github.motalim-ai.zajil` (بشرطة).
  - **ويبقى `io.github.motalim_ai.zajil`** المعرّف الأساسي في كل مكان آخر، ومنه اسم مضيف Native Messaging.
  - **يُحسم قبل M4**، لأن M4 هي أول مرحلة تنشئ تطبيق Tauri.
