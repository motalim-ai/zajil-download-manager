# مقارنة الميزات مع IDM (Parity)

| البند | القيمة |
|---|---|
| الحالة | مسودة للموافقة (M0) |
| آخر تحديث | 2026-10-23 |
| المصدر | **وثائق IDM العامة فقط**: صفحة الميزات، والأسئلة الشائعة، وصفحة المساعدة، وسجل التغييرات، وصفحات المتاجر. **لم نحلل البرنامج نفسه** (انظر [قاعدة الغرفة النظيفة](../CONTRIBUTING.md#قاعدة-الغرفة-النظيفة)) |

هذه المقارنة **من منظور المستخدم فقط**: ماذا تقول الوثائق إن البرنامج يفعل. لا تصف كيف يعمل من الداخل، ولا تنسخ تصميمه.

**معاني الحالة**:
- **موجودة**: موجودة في زاجِل الآن. لا يوجد شيء بهذه الحالة بعد، لأننا في M0.
- **في المرحلة Mx**: مخطط لها في هذه المرحلة.
- **لن نعملها**: مع ذكر السبب.

## 1. التحميل والمحرّك

| ميزة IDM (حسب وثائقه العامة) | زاجِل | ملاحظات |
|---|---|---|
| تسريع التحميل بالتقسيم الديناميكي للملف | في المرحلة M2 | نطبقه من المعيار ومن وصفنا الخاص: الجزء الأطول وقتًا يُقسم |
| حتى 32 اتصالًا لكل تحميل | في المرحلة M2 | |
| إعادة استخدام الاتصالات | في المرحلة M2 | keep-alive وHTTP/2 حسب المكتبة |

| بروتوكولات HTTP وHTTPS | في المرحلة M1 | |
| بروتوكول FTP | **سؤال للمالك** | غير مذكور في نطاق 1.0. انظر [ROADMAP](ROADMAP.md#خارج-النطاق) |
| بروتوكول MMS | لن نعملها | بروتوكول متوقف عمليًا |
| HTTP/2 | في المرحلة M2 | حسب دعم المكتبة، وأداؤه يُقاس |
