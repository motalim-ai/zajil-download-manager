# ملف الإعدادات `settings.json`

إعدادات واجهة سطح المكتب (M4). يقع في مجلد البيانات بجانب `queues.json` و`categories.json`، وبنفس قواعدهما (ADR-0007):
- رقم نسخة للمخطط، وقراءة صارمة: حقل غير معروف يُرفض.
- بصمة SHA-256 للملف.
- كتابة آمنة لا يقرؤها إلا صاحبها.
- قفل `settings.lock` من القراءة إلى الكتابة.
- الملف التالف لا يُكتب فوقه أبدًا.
- الحجم الأقصى 64 كيلوبايت عند القراءة. والكتابة لا تفحص هذا الحد بعد، فقيمة طويلة جدًا قد تُكتب ثم تُرفض عند القراءة (#58).

المحرك نفسه لا يقرأ هذا الملف. الواجهة تمرر القيم إليه.

```json
{
  "format": "zajil-settings",
  "schema_version": 1,
  "language": "ar",
  "theme": "system",
  "digits": "latn",
  "download_dir": null,
  "connections": 8,
  "notifications": true,
  "clipboard": false,
  "update_check": true,
  "updated_at": "2026-10-25T12:00:00Z",
  "checksum": "sha256:…"
}
```

| الحقل | القيم |
|---|---|
| `language` | `ar` (الافتراضي) أو `en`. يتغير دون إعادة تشغيل |
| `theme` | `system` (الافتراضي) أو `light` أو `dark` |
| `digits` | `latn` للأرقام 123 (الافتراضي، باختيار المالك في التصميم) أو `arab` للأرقام ١٢٣ |
| `download_dir` | مجلد التحميلات الجديدة، أو `null` لمجلد التحميلات في النظام. يجب أن يكون مسارًا مطلقًا بلا `..`، ونصًا سليمًا بلا رموز خفية، مثل مجلد الفئة |
| `connections` | عدد الاتصالات لكل تحميل جديد، من 1 إلى 32 |
| `notifications` | إشعار حين ينتهي تحميل أو يفشل: `true` (الافتراضي، وكذلك إذا غاب الحقل) أو `false` |
| `clipboard` | مراقبة الحافظة (M5): رابط تحميل يُنسخ يفتح حوار الإضافة. `false` (الافتراضي، وكذلك إذا غاب الحقل) أو `true` |
| `update_check` | فحص التحديث عند البدء (#124): يسأل GitHub عن آخر إصدار، ولا يُنزّل شيئًا. `true` (الافتراضي، وكذلك إذا غاب الحقل) أو `false` |

حد السرعة العام **ليس هنا**: يبقى في `queues.json` (`settings.speed_limit`)، حيث يقرؤه منفّذ القوائم و`zajil`.
