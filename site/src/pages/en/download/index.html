Install

Zajil is a free and open-source project, and will not be signed by Apple or Microsoft. What shows a file is ours: the SHA256SUMS checksums published with each release, the code on GitHub, and installers built automatically on GitHub only. So a warning shows the first time you open it; here is how to get past it.

Windows: SmartScreen

  1. The browser may first warn that the file is not commonly downloaded: choose Keep. In Edge: … → Keep → Show more → Keep anyway.
  2. Run the installer. When “Windows protected your PC” shows, press More info, then Run anyway.

Windows 11, Smart App Control: when it is on, Windows blocks unsigned programs, with no button to skip it and no exception for one program. To run Zajil it has to be turned off:

  1. Open Windows Security → App & browser control → Smart App Control settings.
  2. Choose Off.
  3. Mind: on some versions of Windows 11 it cannot be turned on again without reinstalling Windows. Read Windows' message before you confirm; the choice is yours.

macOS: Gatekeeper

  1. Open the .dmg and drag Zajil to the Applications folder.
  2. Open Zajil. A message says macOS cannot verify it: press Done (or OK).
  3. Open System Settings → Privacy & Security, scroll down to Security, press Open Anyway next to the message about Zajil, and confirm with your password. The button stays for about an hour after the step before.
  4. If macOS asks again, press Open Anyway. After that Zajil opens as usual.

Linux

The .deb, from the folder you downloaded it to:

sudo apt install ./Zajil_*_amd64.deb

Or the AppImage, with no install:

chmod +x Zajil_*_amd64.AppImage
./Zajil_*_amd64.AppImage

Adding the browser extension

Install Zajil and start it once first: it is Zajil that registers itself with the browsers. If the extension cannot reach it, open Zajil's Settings → “Browser” → “Fix the browser integration”.

Chrome and Edge (until it is in the stores):

  1. Unzip the extension's file into a folder you keep. Do not delete it after adding the extension.
  2. Open chrome://extensions (or edge://extensions in Edge), and turn on Developer mode.
  3. Press Load unpacked and choose the folder you unzipped.
  4. The extension's ID must be nbgfmhkjbkmldddelnepobieoehecmif. Zajil accepts no other.

Firefox: Firefox needs an extension signed by Mozilla, and we will put its link here when it is ready. To try it before that: open about:debugging#/runtime/this-firefox, press Load Temporary Add-on, and choose manifest.json inside the unzipped extension. It stays until Firefox closes.

On Linux: browsers installed with Flatpak, and Chromium from snap, cannot start a program outside their sandbox, so the extension cannot reach Zajil from them.

Checking the files

Download SHA256SUMS from the release page into the same folder as the files, then run in that folder:

macOS:

shasum -a 256 -c SHA256SUMS --ignore-missing

Linux:

sha256sum -c SHA256SUMS --ignore-missing

Windows (PowerShell):

$f = Get-Item .\Zajil_*_x64-setup.exe
(Get-FileHash $f).Hash -eq (Select-String -SimpleMatch $f.Name .\SHA256SUMS).Line.Split(' ')[0]

On macOS and Linux every line must end in OK; on Windows the command must print True. If not, do not run the file, and tell us on GitHub.
